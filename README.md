# 🌾 Smart Agriculture System using Machine Learning

## 📖 Overview

The Smart Agriculture System is an AI-powered web application designed to help farmers make informed agricultural decisions. The system integrates Machine Learning and Deep Learning models to predict crop diseases, recommend suitable crops and fertilizers, estimate water requirements, schedule irrigation, predict weather conditions, and estimate crop yield.

This project aims to improve agricultural productivity through intelligent, data-driven farming solutions.

## 📊 Modules

### 🌱 Crop Recommendation
Recommends the most suitable crop based on soil type and environmental conditions.

### 🍃 Disease Detection
Uses a CNN (MobileNetV2) model to identify diseases from crop leaf images.

### 🌾 Crop Yield Prediction
Predicts crop yield using historical agricultural data and Machine Learning.

### 🌿 Fertilizer Recommendation
Suggests the appropriate fertilizer based on crop and soil information.

### 💧 Water Requirement Prediction
Predicts the amount of water required for different crops.

### 🚜 Irrigation Recommendation
Provides irrigation schedules based on crop type, soil condition, and weather.

### 🌦 Weather Prediction
Predicts weather conditions to assist in agricultural planning.

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/AyarinJusme/Smart-Agriculture-System.git
```

Go to the project folder

```bash
cd Smart-Agriculture-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Django server

```bash
python manage.py runserver
```

Open your browser

```
http://127.0.0.1:8000/
```
